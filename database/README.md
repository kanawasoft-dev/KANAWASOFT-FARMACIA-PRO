# Database

Esquema PostgreSQL, migrações versionadas, índices, restrições e dados exclusivamente fictícios para desenvolvimento.

As tabelas devem suportar tenant/farmácia, filiais, utilizadores, produtos, lotes, movimentos de stock, compras, vendas, pagamentos, receitas, caixa e auditoria. Definir chaves estrangeiras e políticas de isolamento antes de produção.

# Frontend

Aplicação web da farmácia.

Estrutura prevista:
- `index.html` — ponto de entrada.
- `assets/css/` — estilos.
- `assets/js/` — aplicação e módulos.
- `assets/img/` — imagens e logótipos.

A interface deve consumir a API do backend. Não colocar credenciais nem regras críticas de negócio exclusivamente no browser.

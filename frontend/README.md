# KANAWA SOFT FARMÁCIA

## Conteúdo
- `index.html` — estrutura da aplicação.
- `styles.css` — interface responsiva.
- `app.js` — navegação, módulos, formulários, CRUD demonstrativo, pesquisa, auditoria e exportação JSON.

## Como executar
1. Extraia a pasta.
2. Abra `index.html` num navegador moderno.
3. Os dados de demonstração ficam guardados no `localStorage` do navegador.

## Módulos incluídos
Painel; Vendas/POS; Medicamentos e produtos; Gestão de stock; Lotes e validade; Compras; Fornecedores; Clientes; Receitas médicas; Caixa e turnos; Finanças; Funcionários; Utilizadores e perfis; Relatórios; Configurações; Auditoria.

## Aviso importante
Esta é uma base de front-end demonstrativa, não um sistema farmacêutico certificado nem pronta para produção. O `localStorage` não é uma base de dados segura nem partilhada entre computadores. Antes de operar uma farmácia real, implementar API/backend e PostgreSQL, autenticação e permissões no servidor, backups, logs invioláveis, controlo de lotes/validade, regras de dispensação e prescrição, integração fiscal e validação da legislação da autoridade farmacêutica e fiscal do país. Não utilizar para dispensação real sem validação profissional e legal.
